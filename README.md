Dark Pattern Analysis

This project analyzes deceptive design practices (dark patterns) in digital interfaces and their impact on user behavior.

Project Overview

* Identified different types of dark patterns
* Analyzed user interaction data
* Created dashboards to highlight manipulative design trends

Tools & Technologies

* Excel / Power BI
* Data Analysis
* Visualization Techniques

Key Features

* Categorization of dark patterns
* User behavior insights
* Trend analysis across platforms

Files Included

* Dataset (Excel)
* Dashboard file
* Screenshots

Outcome

Enhanced understanding of unethical UX practices and their measurable impact.
